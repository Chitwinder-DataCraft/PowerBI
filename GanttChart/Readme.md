\# Power BI Gantt Chart



A project timeline built with the Gantt visual (preview) in Power BI Desktop.



\## Contents

\- `GanttChart-PBI.pbip`: open this in Power BI Desktop

\- `Gantt-data.csv`: sample data (13 tasks, 4 phases, Jan-Apr 2026)

\- `ThemeFile.json`: report theme



\## How to use

1\. Enable \*Power BI Project (.pbip) save option\* under File > Options > Preview features.

2\. Open `GanttChart-PBI.pbip`.

3\. If prompted, point the data source to your local `Gantt-data.csv`.
